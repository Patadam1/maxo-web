# Maxó · Comida casera cocinada en leña

Web del Bar-Restaurante Maxó (C. Paloma, 72 · Pedro Muñoz).

Es una página estática (`index.html`) publicada con GitHub Pages.

## Cambiar datos

Todo está en el bloque `const MAXO = { ... }` al final de `index.html`:

- teléfono
- horario
- dirección
- Instagram
- nota y número de opiniones de Google
- **menú del día**: rellena `primeros`, `segundos`, `postres`, `precio` y `nota`. El bloque aparece solo en la web en cuanto tiene platos.

## Fotos

Están en `assets/fotos/`. Para cambiar una, sustituye el archivo manteniendo el mismo nombre, o cambia la ruta en `index.html`.
